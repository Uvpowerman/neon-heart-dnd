# Неоновое сердце

Интерактивное киберпанк-приключение в стиле DnD для учеников 5–11 классов.
Игра рассчитана на 3–8 игроков и примерно 60 минут.

## Играть онлайн

[Открыть «Неоновое сердце»](https://uvpowerman.github.io/neon-heart-dnd/)

## Возможности

- четыре подробные тактические карты;
- перемещение жетонов мышью и касанием;
- добавление, удаление и подпись жетонов;
- отслеживание текущих и максимальных ОЗ;
- броски d4, d6, d8, d10, d12 и d20;
- автоматическая очередь инициативы;
- карточки героев и противников;
- правила, сюжет, этапы и варианты финала.

## Важно

Состояние карты хранится в памяти открытой страницы. Если несколько игроков
откроют сайт на разных устройствах, их действия не будут синхронизироваться.
